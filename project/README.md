# Project Directory

This directory is the fixed location for a custom EBcLfSA project as described in the User's Manual.

Following the User's Manual populates this directory with example BitBake layers and Kas project configurations.

Being located within the workspace, this directory is accessible in the development container and the BitBake layers therein satisfy the git worktree requirement of Kas.

This is the defined place where you can store your user-specific image and package recipes without them being overwritten by future updates.
